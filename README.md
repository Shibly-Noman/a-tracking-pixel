# AdTech Pixel Tracker

This project is an AdTech Pixel Tracker built with Node.js and TypeScript. It provides functionality for tracking pixel events and analyzing data for advertising purposes.

- [API Endpoints](#api-endpoints)

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/adtech-pixel-tracker.git
   ```

2. Navigate to the project directory:
   ```
   cd adtech-pixel-tracker
   ```

3. Install the dependencies:
   ```
   npm install
   ```

## Usage

To start the application, run:
```
npm start
```

The server will start on `http://localhost:3000`.

## API Endpoints

- `POST /track`: Track a pixel event.
- `GET /analytics`: Retrieve analytics data.

## Testing

To run the tests, use:
```
npm test
```
